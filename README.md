# ことばのにわ

小学生向けの、絵と日本語音声で学ぶ4択教材です。

公開サイト: https://ceo01sasaki-dot.github.io/kotoba-garden/

- 動詞100語・30コース・300問。「たたく」はコース7・17・27に収録しています。
- 名詞300語・60コース・600問。生活で使う語を中心に見直し、ジャンルごとにコースを構成しています。
- 名詞の4択も同じジャンルから選び、似た意味・絵の選択肢は組み合わせません。
- 正解位置は挑戦・再挑戦・間違えた問題の復習で毎回並べ替えます。同じ問題・形式の直前の正解位置をブラウザに保存し、次回は別の位置にします。答え合わせ中は並べ替えません。
- 名詞コースを再編したため、旧名詞の点数は「せんせいへ → 以前の 名詞の 記録」で保管します。
- 学習記録はブラウザ内に保存します。氏名の入力・児童別の管理・端末間の同期はありません。
- 日本語の合成音声は端末の音声機能を使用します。日本語音声の追加や通信が必要な端末もあります。

## 開発・検証

`dist/` が公開ファイルです。パッケージのインストールやビルドは不要です。

```sh
node verify.cjs
python build-download.py
python -m http.server 8080 --directory dist
```

`verify.cjs` は全900問のカバー範囲、4択の一意性、ジャンルの一致、形式のバランス、採点、復習の正解位置変更、回答後の配置固定、旧成績の保管を検証します。

`build-download.py` は画像・コードを埋め込んだHTMLとZIPを `dist/downloads/` に作成します。ダウンロード版は更新のたびに再作成します。

## 公開・更新

- `main`: `dist/` と検証・説明ファイルを管理します。
- `gh-pages`: `dist/` の中身をルートに配置します。GitHub Pages は `gh-pages` の `/ (root)` から公開します。
- 更新時は `main` と `gh-pages` の両方へ同じ教材を反映し、Pagesの公開処理と公開ファイルを確認します。
- GitHub Pagesに公開する画像・JS・CSSへの参照は相対パスです。
