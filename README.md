# ことばのにわ

小学生向けの日本語学習教材です。イラストと日本語音声を使い、4択で名詞・動詞を練習します。

- 動詞100語：30コース・300問
- 名詞300語：60コース・600問
- 絵からことば、ことばから絵の2形式
- 読み上げ速度の調整、採点、間違えた問題の復習
- ブラウザ内への学習記録の保存（氏名入力・端末間同期なし）

## 使い方

`dist/index.html` をブラウザで開きます。または、このフォルダーで次のコマンドを実行します。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000` にアクセスしてください。HTML・CSS・JavaScriptのみで動き、npmのインストールやAPIキーは不要です。

## 音声

Web Speech APIによる日本語合成音声を使用します。授業で使う端末に日本語音声があることを確認してください。発音・対応状況・通信の必要性は端末やブラウザによって異なります。

## ファイル

- `dist/app.js`：画面・出題・採点・音声・学習記録
- `dist/verbs.js`：動詞と独自SVGイラスト
- `dist/nouns.js`：名詞データとイラスト
- `dist/style.css`：画面デザイン
- `dist/download.html`：ダウンロード案内
- `build-download.py`：単体HTMLとZIPを生成
- `verify.cjs`：語彙・800問の選択肢・採点・復習の確認

## 更新時の確認

```sh
node verify.cjs
python3 build-download.py
```

ダウンロード版は `dist/downloads/` に生成します。Web版で変更した内容を反映するには、再生成が必要です。

## 別サーバーへの配置

`dist/` の内容を静的Webサイトとして配置できます。学校ネットワークからのアクセス可否は学校の設定によります。

ローカルHTMLでは学習記録が保存できない端末があります。ダウンロード版は自動更新されません。

## イラストの確認

77語は2コマで動作の前後を示します。判断基準と確認の限界は `ART_REVIEW.md` を参照してください。
学校で使う「ならぶ」「くばる」「はこぶ」などを追加しています。
動詞100語版では旧動詞コースの点数を別に保管します。名詞はコース1〜25の記録を引き継ぎ、旧コース26〜50は別に保管します。
